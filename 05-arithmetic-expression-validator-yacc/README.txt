Arithmetic Expression Validator (YACC)
==========================================================

AIM
---
To recognize a valid arithmetic expression using YACC.

FILES IN THIS FOLDER
--------------------
arith_expr.y        YACC grammar file
arith_expr.l        Lex program
README.txt          This guide

HOW TO COMPILE & RUN  (Linux lab system)
----------------------------------------
1. lex arith_expr.l
2. yacc -d arith_expr.y
3. cc y.tab.c lex.yy.c -o exp5 -ll

   (if your system complains about -ll, use -lfl instead)

4. ./exp5

   lex.yy.c and y.tab.c are generated by steps 1 and 2 —
   y.tab.h holds the token codes shared by both tools.

-------------------
