S7 COMPILER DESIGN LAB  —  EXPERIMENT 6
Identifier Recognizer (YACC)
==========================================================

AIM
---
To generate a YACC specification to recognize a valid identifier which starts with a letter followed by any number of letters or digits.

FILES IN THIS FOLDER
--------------------
exp6.y              YACC grammar file
exp6.l              Lex program
README.txt          This guide

HOW TO COMPILE & RUN  (Linux lab system)
----------------------------------------
1. lex exp6.l
2. yacc -d exp6.y
3. cc y.tab.c lex.yy.c -o exp6 -ll

   (if your system complains about -ll, use -lfl instead)

4. ./exp6

   lex.yy.c and y.tab.c are generated by steps 1 and 2 —
   y.tab.h holds the token codes shared by both tools.
