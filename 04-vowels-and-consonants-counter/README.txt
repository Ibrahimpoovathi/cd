Vowels & Consonants Counter

AIM
---
To count the number of vowels and consonants in a given string using Lex.

FILES IN THIS FOLDER
--------------------
vowels.l            Lex program
README.txt          This guide

HOW TO COMPILE & RUN  (Linux lab system)
----------------------------------------
1. lex vowels.l
2. cc lex.yy.c -o exp4 -ll

   (if your system complains about -ll, use -lfl instead)

3. ./exp4

   Type your input, then press Ctrl+D to signal end-of-file
   and see the result.

WHAT YOU SHOULD SEE
-------------------
Enter a string:
Hello World

Vowels = 3
Consonants = 7
