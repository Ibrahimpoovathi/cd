HOW TO COMPILE & RUN  (Linux lab system)
----------------------------------------
1. lex lexical.l
2. cc lex.yy.c -o exp1 -ll

   (if your system complains about -ll, use -lfl instead)

3. ./exp1

   The program opens input_lex.c by itself and
   scans it — no typing needed. Keep both files in the same folder.
